Terms and Data Use

Secure Connector Terms.

This personal-use connector helps the authorized user copy data into a local private archive.

Scope

  • The connector is for personal data access only.
  • The connector requests access only after authorization.
  • The authorized user can revoke access through the source service.

Data Use

  • The public site does not collect, store, or transmit user data.
  • The callback page reads the browser URL only to help the user copy it.
  • The local connector stores downloaded data only in the user-controlled archive.
  • The local connector stores long-lived credentials only in the user-controlled keychain.

Sharing

  • The connector does not sell data.
  • The connector does not use data for advertising.
  • The connector does not share data except as needed to request authorized data from the source service.

Security

  • The site uses HTTPS through GitHub Pages.
  • The site has no account system, database, analytics, or server-side storage.
  • The user remains responsible for protecting local files and device access.
